# PricingCard

Pricing cards compare plans on the pricing page and in upgrade dialogs.

## The consumer provides

- `plan`, `price`, `period`, `description` (who it's for), `features` (what you get, as outcomes), `cta`, `featured` (one per row), `current`.

## Rules

- Prices in the viewer's currency with the period beside them; tabular figures.
- Features list what changes for the person ("Unlimited CVs and share links"), not internal limits.
- One featured card with the gold "Most chosen" flag; its button is primary, the others secondary.
