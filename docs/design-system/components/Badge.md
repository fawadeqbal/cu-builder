# Badge

Badges label a status, a count or a category in a word or two: "Ready", "3 to check", "In use", "ATS-friendly", "Optional".

## The consumer provides

- `children` (1–3 words), `tone` (`neutral`, `brand`, `success`, `warning`, `danger`, `info`, `highlight`), `variant` (`soft` default, `solid` for the one badge that must stand out, `outline` for categories), `icon` or `dot`, `pill`.

## Rules

- Status always pairs colour with a word and usually an icon; never colour alone.
- `highlight` (gold) is for good news and premium ("New", "Most chosen"), never for warnings.
- Badges are not buttons. A removable or selectable label is a `Chip`.
