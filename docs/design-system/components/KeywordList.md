# KeywordList

Keyword lists show which of a job's skills a CV already shows and which are missing, the core of job matching and tailoring.

## The consumer provides

- `found`, `missing`, and `required` (the subset of missing the posting calls essential, marked with a red asterisk).

## Rules

- Found keywords sit on `gold-soft` like a highlighter; missing ones are outlined and quiet.
- Under the list, say what to do: "Add these only if you have used them." Never auto-insert missing skills.
