# Voice and content

CV Builder sounds like a calm, experienced career adviser: plain words, short sentences, no hype. It writes to the person as **you** and about itself rarely ("we" only when the product did something: "We read your PDF").

## Casing and punctuation

- Sentence case for everything: page titles, buttons, tabs, menu items ("Members & invites", "Save to tracker").
- No full stops on labels, buttons, titles or single-sentence hints; full stops in multi-sentence copy.
- Numbers as digits ("4 jobs", "3 to check"), currencies with their code or symbol ("PKR 450,000", "$39"), dates as "Fri 24 Oct" in lists and "Friday 24 October" in sentences, times as "5:00 pm" (en) or 24-hour where the locale prefers.

## Words we use

| Say | Not |
| --- | --- |
| CV | Resume (except the "US resume" format) |
| Application | Job card, entry |
| Save to tracker | Add to pipeline |
| Expert | Coach, consultant (except the Coaching service) |
| AI credits | Tokens, points |
| Share link | Public URL |
| Organisation (university, career centre, agency) | Tenant, workspace |
| Delete / Move to trash | Remove permanently, destroy |

## Patterns

- **Buttons** start with a verb and say what happens: "Download PDF", "Book coaching", "Send invitation".
- **Empty states** invite: "Track every application in one place", then one sentence and one action.
- **Errors** say what went wrong and how to fix it: "We couldn't read that file. Upload the original PDF or Word file."
- **Success toasts** state the fact in past tense with Undo: "Moved to Interview · Undo".
- **Plan gates** say what the person gets, not what they lack: "Get mock interviews with Premium".
- **AI** is a helper, never a person: "Write it for me", "Pick a summary". No "I" from the assistant.

## Localisation

- Write strings that translate: no idioms, no puns, no text baked into images.
- Leave room: Urdu and Arabic run 20–30% longer than English and Nastaliq needs twice the line height.
- Keep names, emails, URLs and code in their original direction inside right-to-left text.
